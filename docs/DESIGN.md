# 《第七间教室》剧情设计

> ⚠️ 本文档包含完整剧透。

## 核心构思

参考东野圭吾的几个手法：

- **自白不是终点**（《恶意》）：凶手很早就自首了，真正的谜题是他为什么要说谎。
- **为他人顶罪**（《嫌疑人 X 的献身》）：两个人互相保护，都抢着说「人是我杀的」。
- **动机才是真相**：凶器和手法在第一章就基本查清，后面几章一层层剥开的是「为什么」。
- **克制的结局**：没有坏人得到报应的痛快，只有一个需要主角自己做的选择。

## 人物

| 人物 | 身份 | 在案件中的位置 |
|---|---|---|
| 夏川（玩家） | 县警刑警，青岚高中毕业生 | 叙述者 |
| 宋小满 | 新人刑警，夏川的搭档 | 负责提问和吐槽，帮玩家理清思路 |
| 赵队 | 辖区刑事课长 | 想尽快结案，给主角施加时间压力 |
| 许蔓 | 法医 | 提供「两处伤相隔二十分钟」这个关键 |
| 周慕白 | 死者，美术教师 | 成名作《海与少女》是学生白芸画的 |
| 陈伯（陈守义） | 校工 | **真凶**。「第七间教室」的制造者 |
| 白芷 | 高二学生，白芸的妹妹 | 第一个伤害周慕白的人，以为自己杀了人 |
| 白芸 | 白芷的姐姐，已故 | 去年台风夜坠海 |
| 顾明远 | 数学老师 | 红鲱鱼，匿名信的作者，关键的「耳证人」 |
| 林晓 | 高一摄影社 | 照片提供时间线 |

## 真相

**去年 10 月 11 日，台风夜。** 白芸发现《海与少女》被老师冒名参赛，拿着素描本要去找校长。
周慕白在海堤上追上她，抢素描本时她失足坠海。她在水里喊救命，周慕白却先捡起了素描本——本子是干的。
坠海前，白芸给最信任的陈伯打了电话（18:07），陈伯在修配电房，没接到。

**之后。** 陈伯在准备室柜子里发现了那本干燥的素描本。他不识几个字，不知道该找谁，
就在准备室装了定时器，每周五 18:07 亮灯，在黑板上抄一句素描本里的话，等着有人来问。「第七间教室」的传闻由此而来。

**案发当天（周五）**

| 时间 | 事件 |
|---|---|
| 17:52 | 白芷撑蓝伞进入旧校舍（林晓拍到） |
| 18:02 | 白芷与周慕白在准备室对质，手机开始录音 |
| 18:07 | 定时器亮灯 |
| 约 18:10 | 周慕白抢手机，白芷推开他，他后脑撞上画架昏倒。手机壳摔碎一角 |
| 18:16 | 白芷以为他死了，丢下手机和伞逃走（林晓拍到） |
| 18:20 | 顾明远进二楼办公室，想偷回匿名信 |
| 18:31 | 陈伯例行上楼，发现周慕白醒来。周慕白第一句话是让他把手机拿给自己 |
| 18:35 | 两人对话，周慕白承认海堤上的事。顾明远在楼下听到「她喊的是救命，你先捡的却是画册」 |
| 约 18:40 | 陈伯用石膏像击中坐在地上的周慕白头顶，致死 |
| 18:41 | 陈伯站在窗边（林晓拍到戴鸭舌帽的人影） |
| 之后 | 陈伯推倒梯子伪装意外，擦拭石膏像，藏起白芷的伞和手机 |
| 19:07 | 定时器关灯 |
| 19:13 | 手机没电，录音结束 |

**陈伯为什么说谎**：如果说出真实动机，就要说出那天傍晚发生了什么，白芷推人的事就会暴露。
所以他编了「偷卖画材」的动机，把时间说成七点，想把白芷从整件事里摘出去。

**白芷为什么也自首**：她以为是自己那一推杀死了周慕白，不愿让陈伯替她坐牢。

## 结构与反转

| 章 | 玩家此时以为 | 推理揭开 |
|---|---|---|
| 第一章 现场 | 意外？ | 他杀；白芷在场；两处伤之间有第二个人 |
| 第二章 自白 | 陈伯自首了，结案？ | 自白全是破绽 → 陈伯在替白芷顶罪？→ 白芷也自首 |
| 第三章 雨声 | 白芷是凶手，陈伯顶罪？ | 白芷离开时周慕白还活着；陈伯真的杀了人，他隐瞒的是动机 |
| 录音 | — | 一年前海堤上的真相 |
| 终章 | — | 玩家选择：报告里要不要写白芷的那一推 |

## 结局

- **真相结局「海在春天会变暖」**：全部写进报告。白芷被调查后不起诉，《海与少女》的作者改回白芸。
- **沉默结局「替你背负的重量」**：隐去白芷的那一推，夏川替她背负这个秘密。

## 可扩展方向

- 加入「时间线拼图」推理：让玩家把照片和证词按时间排列。
- 加入证人「证言对质」：逐句质证、找出矛盾句。
- 第二个案子：顾明远、林晓都可以发展成新故事的主角。
