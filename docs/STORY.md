# 《第七间教室》剧情设定

> 类型：校园 · 恋爱（主） / 悬疑（辅）
> 引擎：WebGAL
> 篇幅目标：5 章 + 3 个结局，约 2～3 小时流程

## 一句话简介

转学到青岚高中的主角听说了一个传闻：旧校舍三楼明明只有六间教室，
可每到周五傍晚 6:07，走廊尽头会多出一间亮着灯的「第七间教室」，黑板上还会留下新的字。

## 世界观

- **青岚高中**：靠海的小城公立高中。新教学楼启用后，旧校舍只剩图书室和几间社团活动室在用，三楼整层封闭。
- **第七间教室的传闻**：一年前开始流传。见过的人说黑板上写着奇怪的句子，比如「还差三幅」「春天的那一幅在最高的地方」。

## 主要角色

| 角色 | 定位 | 性格 | 秘密 / 动机 |
|---|---|---|---|
| **主角**（默认名：陆远，可自定义） | 二年级转学生 | 嘴上嫌麻烦，其实很会照顾人 | 家里经常搬家，从没在一所学校待满一年，所以不太敢交朋友 |
| **白芷** | 同年级的图书委员，悬疑线核心女主 | 安静、少话、说话很直接；喜欢旧书的气味 | 姐姐**白芸**去年突然退学离开小城，只留下一句「去第七间教室找我」 |
| **苏晴** | 同班同学、摄影社社长，日常线核心女主 | 元气、好奇心旺盛、行动派 | 摄影社只剩她一个人，如果招不到新社员就要被撤销 |
| 老周 | 校工 | 沉默寡言，总在旧校舍附近 | 受白芸之托，每周五在准备室黑板上写下一条「提示」 |
| 白芸 | 白芷的姐姐，前美术社社长 | 只出现在回忆、画和信里 | 因家庭变故突然退学，把画给妹妹的四幅画藏在了旧校舍 |

## 悬疑主线真相（剧透）

「第七间教室」其实是三楼尽头被隔板封起来的**旧美术准备室**。门藏在一排储物柜后面，从走廊看过去像一面墙。

白芸退学前和老周约定：每周五傍晚，老周打开准备室的灯，在黑板上写一条提示，
引导白芷找到藏在学校各处的「四季」四幅画。画背后连起来，是姐姐写给妹妹的一封信。

白芷一直以为这是灵异事件，又害怕又放不下，一年来一个人在查。主角和苏晴的加入让事情终于有了进展。

**悬疑的分寸**：没有真正的灵异，也没有恶人。紧张感来自黄昏、空教室和传闻，结局要温暖。

## 关键变量

| 变量 | 含义 | 说明 |
|---|---|---|
| `me` | 主角名字 | 开场输入，默认「陆远」 |
| `aff_bai` | 白芷好感度 | 由选项增减 |
| `aff_su` | 苏晴好感度 | 由选项增减 |
| `clue` | 已找到的线索数（0～4） | 对应「四季」四幅画 |

## 结局分歧（终章）

| 结局 | 条件 | 内容 |
|---|---|---|
| 白芷结局「写给你的信」 | `clue >= 4` 且 `aff_bai > aff_su` | 读完姐姐的信，白芷第一次笑着哭；文化祭后在准备室告白 |
| 苏晴结局「取景框里的你」 | `aff_su >= aff_bai` 且 `aff_su >= 3` | 摄影社保住了；在天台用一张照片告白 |
| 普通结局「放学后」 | 其他情况 | 谜团解开，三人成为好友；主角决定这次不再转学 |

## 美术素材清单

- 立绘：`scripts/sprites/characters.mjs` 矢量绘制的日系风格立绘（白芷：黑长直姬发、蓝瞳、蓝色发饰；苏晴：栗色短发、呆毛、琥珀瞳、双色发夹、胸前挂相机）
- 背景：`scripts/gen_placeholders.py` 生成的占位图
- 替换为正式美术时**保持文件名不变**即可。

- 背景（1920×1080）：`title` `school_gate` `classroom` `classroom_dusk` `corridor_old` `library` `rooftop` `black`
- 立绘（约 900×1440，透明背景 PNG）：
  - 白芷：`baizhi_normal` `baizhi_smile` `baizhi_surprised` `baizhi_sad`
  - 苏晴：`suqing_normal` `suqing_smile` `suqing_surprised` `suqing_pout`
- 待补：BGM（日常、黄昏、悬疑、温情）、音效（脚步声、开门声、上课铃）
