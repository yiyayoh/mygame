# 第七间教室

一部在浏览器里玩的**社会派文字推理游戏**，风格参考东野圭吾。

> 青岚高中旧校舍三楼明明只有六间教室，可每到周五傍晚 6:07，走廊尽头就会多出一间亮着灯的「第七间教室」。
> 一个雨夜，美术老师周慕白死在了那间不存在的教室里。
> 第二天，两个人先后走进警局，都说：人是我杀的。
>
> 而一年前的台风夜，有一个女孩在东堤上喊过救命。

## 玩法

- **调查**：在地点里勘查物证，向人物询问证词，收集线索。
- **出示线索**：把线索摆到证人面前，戳破他们的谎言。有些真相只有这样才能问出来。
- **推理**：每章最后回答一组问题，选出答案或者从线索本里出示证据。答错会被记下来，影响最终评价。
- **推理题型**：单选、出示证据、时间线排序、多选，以及逐句选择陈述、配上证据的「证言对质」。最后一章还有没有标准答案的提问。
- **发现矛盾**：对质需要选对陈述，并配上能反驳它的证据；可以自由更换选句，提交前不判错。两级思路提示不扣评价。完成后，发现会记入线索本的「推理记录」，结局也会显示本轮发现的数量。
- **线索本**里有「人物档案」，随着调查逐条解锁每个人的过去。
- **查找线索**：线索本支持按类别筛选、按名称或内容搜索；出示证据时也能使用。
- **回看与读档**：回看保留已读的跨章正文，新存档会恢复当前句和最近正文。旧存档仍可使用，但无法补回此前没有记录的正文。
- **阅读设置**：可调整字号和文字出现速度，雨声开关也在设置里。设置独立保存。
- **场景配乐**：七套原创的轻钢琴、长音和低频节拍配乐，随剧情、调查和推理自动切换并淡入淡出。默认音量 35%，首次点击游戏后播放；标题页和设置中都可关闭，音量与静音偏好会记住。音乐与雨声独立控制，切到后台会暂停声音。
- 人物的「话题已问完」仍可继续出示线索；「调查没有进展？」只提醒操作方式，不扣评价。
- 五章正文约三万字、六轮推理、两个结局，通关大约三小时。进度自动保存在浏览器里。

## 本地运行

纯静态网页，不需要安装任何依赖。因为用了 ES Module，需要通过本地服务器打开：

```bash
npm start
# 浏览器打开 http://localhost:8000
```

## 在线部署（GitHub Pages）

到仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**。之后每次推送到 `main` 都会自动部署，
地址是 `https://<用户名>.github.io/mygame/`。

## 目录

```
index.html            页面
css/style.css         样式
js/story.js           剧本入口，合并各章数据
js/story/clues.js     线索与人物档案
js/story/ch1~ch5.js   各章的场景、调查、推理（改剧情只需要改这些文件）
js/engine.js          游戏引擎：播放剧情、调查、出示线索、推理、存档
js/rain.js            雨的画面和合成雨声
js/music.js           原创配乐、场景对应和声音调度（无需音频文件或额外依赖）
assets/favicon.svg    网站图标
docs/DESIGN.md        剧情设计文档（⚠️ 含完整剧透）
tests/validate.mjs    剧本数据校验
tests/playthrough.mjs 浏览器自动通关测试
tests/experience.mjs  阅读恢复、旧存档和界面回归检查
tests/testimony.mjs   证言对质、分级提示、推理记录与中断恢复检查
tests/music.mjs       配乐输出、切换、静音、音量记忆和音频资源回收检查
tests/server.mjs      本地预览与测试服务器
```

## 测试

```bash
node tests/validate.mjs          # 检查线索引用、每章关键线索是否都拿得到
npm install
npx playwright install chromium
npm test                        # 校验 + 阅读界面回归 + 两条完整通关流程
```

已有 Chrome 而无法下载 Playwright 浏览器时，可通过环境变量 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定本机浏览器的完整路径。默认仍使用 Playwright 的 Chromium；测试和本地预览只需要 Node，无需 Python。

## 写剧本速查

`js/story/` 里的台词写法：

```js
'旁白文字',
'【宋小满】角色台词',
'【我】主角（夏川）的台词',
{ clue: 'wounds' },               // 获得线索
{ title: '第一章', sub: '现场' },  // 章节标题卡
```

改完后运行 `node tests/validate.mjs`，它会告诉你有没有引用错的线索，或者卡关的地方。
