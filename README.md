# 第七间教室

一部在浏览器里玩的**文字推理游戏**，风格参考东野圭吾。

> 青岚高中旧校舍三楼明明只有六间教室，可每到周五傍晚 6:07，走廊尽头就会多出一间亮着灯的「第七间教室」。
> 一个雨夜，美术老师周慕白死在了那间不存在的教室里。
> 第二天，两个人先后走进警局，都说：人是我杀的。

## 玩法

- **调查**：在地点里勘查物证，向人物询问证词，收集线索。
- **出示线索**：把线索摆到证人面前，戳破他们的谎言。有些真相只有这样才能问出来。
- **推理**：每章最后回答一组问题，选出答案或者从线索本里出示证据。答错会被记下来，影响最终评价。
- 三章调查、四轮推理、两个结局，通关大约一小时。进度自动保存在浏览器里。

## 本地运行

纯静态网页，不需要安装任何依赖。因为用了 ES Module，需要通过本地服务器打开：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 在线部署（GitHub Pages）

到仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**。之后每次推送到 `main` 都会自动部署，
地址是 `https://<用户名>.github.io/mygame/`。

## 目录

```
index.html            页面
css/style.css         样式
js/story.js           剧本：线索、场景、调查、推理（改剧情只需要改这个文件）
js/engine.js          游戏引擎：播放剧情、调查、出示线索、推理、存档
js/rain.js            雨的画面和合成雨声
docs/DESIGN.md        剧情设计文档（⚠️ 含完整剧透）
tests/validate.mjs    剧本数据校验
tests/playthrough.mjs 浏览器自动通关测试
```

## 测试

```bash
node tests/validate.mjs          # 检查线索引用、每章关键线索是否都拿得到
npm install && npm test          # 校验 + 用 Playwright 自动打通两个结局
```

## 写剧本速查

`js/story.js` 里的台词写法：

```js
'旁白文字',
'【宋小满】角色台词',
'【我】主角（夏川）的台词',
{ clue: 'wounds' },               // 获得线索
{ title: '第一章', sub: '现场' },  // 章节标题卡
```

改完后运行 `node tests/validate.mjs`，它会告诉你有没有引用错的线索，或者卡关的地方。
